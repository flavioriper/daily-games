# Fair Ads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the minors/ads compliance gap (neutral age screen, age-aware ad requests) and add the rewarded-first ad plan: a video for one more hint, a video to double an Arcade run's gold, a video to continue an Arcade run, and one capped interstitial shown only when the player leaves a finished game.

**Architecture:** `core/ads.gd` (autoload `Ads`) stays the only file that touches the AdMob plugin. It gains an age-aware request configuration, an interstitial and a rewarded slot, and a pure pacing model (`core/ad_pacing.gd`) that decides when a full-screen ad may show and how many videos are left today; its numbers are defaults that a remote `config/ads` Firestore document can override. Screens only ask `Ads.can_reward(placement)` / `Ads.show_rewarded(...)` and tell `Ads` when a game finished (`note_finished`) and when the player left it (`leaving_game`). The age lives in `core/age_gate.gd`, asked once by `ui/hud/age_screen.gd` at first launch on a phone, before consent.

**Tech Stack:** Godot 4.7 GDScript, Poing `godot-admob-plugin` v5.1.0 (`addons/admob/gdscript/src/api/`), Firestore REST through `core/backend.gd`, GA4 through `core/analytics.gd`, locale CSVs (`locale/ui.csv`).

**Spec:** `reports/Fair ad monetization for puzzles.md` (the research report; its "The concrete ad plan" table is the requirement list) and the existing ads design `docs/superpowers/specs/2026-09-25-ads-and-remove-ads-design.md`.

## Global Constraints

- Never show a full-screen ad when a game starts: not on tapping a card, not on the win screen's "next level" (`play_level`), not on Arcade "Play again", not on app open or resume. The only interstitial slot is `Ads.leaving_game()` after a screen that finished a game closes back to the list.
- Interstitial defaults: `grace_days` 3 (per install), none until today's hearts == 3, none before 6 finished games today, then at least 2 finished games **and** 4 minutes since the last full-screen ad, none within 4 minutes of a rewarded video, at most 4 a day, never for the CHILD age band.
- Rewarded: always an explicit opt-in button that states the reward before the video; the reward is always given when earned; declining costs nothing. At most 10 rewarded per day across all placements. One video hint per board, never fewer free hints than today (`HINTS` constants unchanged). The doubler doubles **gold, never score**, inside `Wallet.ARCADE_CAP`. One continue per run (the existing `_chance_used`), and a continued run is marked `_boosted` like the gold Second chance.
- Remove-ads owners: no banner, no interstitial; rewarded placements give their reward **without a video**, inside the same daily caps.
- Nothing random, nothing sold for money except the existing `remove_ads`. Gold stays earned-only.
- Age bands: birth year only, age taken as `year_now - birth_year - 1` (the younger possibility). CHILD < 13, TEEN 13-17, ADULT 18+. CHILD: `tag_for_child_directed_treatment` TRUE, max rating G, `npa=1`. TEEN: `tag_for_under_age_of_consent` TRUE, max rating PG, `npa=1`. ADULT: max rating PG, UMP consent as today. The birth year never leaves the device; analytics gets the band only.
- Debug builds always request Google's test units. Real unit ids live in `project.godot` under `ads/`.
- Desktop env overrides (debug builds only), following `ADS_FAKE_BANNER`: `ADS_FAKE_FULL=1` shows a grey stand-in for every full-screen ad; `AGE_SCREEN=1` shows the age screen on the desktop. On desktop without `AGE_SCREEN` the age screen never appears, so harnesses loading `main.tscn` are unaffected.
- Every new player-facing string is a key in `locale/ui.csv` with en, pt (pt-BR) and es. Reimport after editing: `godot --headless --import`, and commit the regenerated `locale/ui.{en,pt,es}.translation` with the CSV (they are tracked).
- Per the project's current MVP rule, no new suite tests: each task proves itself with a throwaway or committed `tests/_probe_*.gd` / harness run, as `tests/_probe_wallet.gd` does (assertions from `_process`, not `_initialize`).
- Work on branch `feat/fair-ads`; merge locally at the end; the user decides the push (a push to main builds and distributes the APK).

## Review Focus

- Offline or no fill: a rewarded button must not appear (or must say `AD_NOT_READY` and stay) when no video is loaded; the player must never lose the hint/continue by tapping during a load failure. Pinned by Task 5's probe (not-loaded path) and Task 8/10 steps.
- A video dismissed early (`on_user_earned_reward` never fires): no reward, no cap consumed, card stays usable. Pinned by Task 5's fake `ADS_FAKE_FULL=skip` mode.
- Day rollover at 00:00 UTC mid-session: daily counters reset, the install grace does not. Pinned in Task 3's probe.
- Remove-ads bought mid-session: interstitial slot stops at once and rewarded buttons switch to their "free" labels. Pinned in Task 5's probe (`Store.owned_changed`).
- Game audio playing under a full-screen ad. Pinned in Task 5 (master bus muted while shown, restored on dismiss or failure).

```gdscript
extends RefCounted

## The player's birth year, asked once at first launch on a phone
## (ui/hud/age_screen.gd) and kept only on this device, so the ads asked
## for suit the player's age: Brazil's ECA Digital (Lei 15.211/2025) and
## the EU's DSA forbid profiling-based ads to minors, and COPPA treats an
## under-13 as a child. Only the band ever leaves the device.
## Plan docs/superpowers/plans/2026-09-29-fair-ads.md, task 1.

const UNKNOWN := -1
const CHILD := 0
const TEEN := 1
const ADULT := 2

static var path := "user://age.cfg"
static var _year := -1

static func birth_year() -> int:
	if _year < 0:
		var cfg := ConfigFile.new()
		cfg.load(path)
		_year = int(cfg.get_value("age", "year", 0))
	return _year

static func set_birth_year(year: int) -> void:
	var cfg := ConfigFile.new()
	cfg.set_value("age", "year", year)
	cfg.save(path)
	_year = year

static func known() -> bool:
	return birth_year() > 0

## A birth year allows two ages; the younger one is taken, so a doubt always
## falls on the protective side.
static func band(year_now: int = int(Time.get_datetime_dict_from_system(true).year)) -> int:
	var y := birth_year()
	if y <= 0:
		return UNKNOWN
	var age := year_now - y - 1
	if age < 13:
		return CHILD
	if age < 18:
		return TEEN
	return ADULT

static func band_name(b: int) -> String:
	return ["child", "teen", "adult"][b] if b >= 0 and b <= 2 else "unknown"

## Forget what was read (a probe that has just pointed `path` elsewhere).
static func reload() -> void:
	_year = -1
```

```gdscript
	if _started:
		return

		return

## child-directed at rating G, a teen is under the age of consent, and
## neither is ever sent a personalised ad; everyone is capped at PG.
func _configure_requests() -> void:
	var b := AgeGate.band()
	var rc := RequestConfiguration.new()
	rc.max_ad_content_rating = RequestConfiguration.MAX_AD_CONTENT_RATING_G if b == AgeGate.CHILD \
		else RequestConfiguration.MAX_AD_CONTENT_RATING_PG
	rc.tag_for_child_directed_treatment = RequestConfiguration.TagForChildDirectedTreatment.TRUE \
		if b == AgeGate.CHILD else RequestConfiguration.TagForChildDirectedTreatment.UNSPECIFIED
	rc.tag_for_under_age_of_consent = RequestConfiguration.TagForUnderAgeOfConsent.TRUE \
		if b != AgeGate.ADULT else RequestConfiguration.TagForUnderAgeOfConsent.UNSPECIFIED
	MobileAds.set_request_configuration(rc)

## The one way an ad request is built here: non-personalised below 18.
func ad_request() -> AdRequest:
	var r := AdRequest.new()
	if AgeGate.band() != AgeGate.ADULT:
		r.extras = {"npa": "1"}
	return r

func _consent() -> void:
	var request := ConsentRequestParameters.new()
	request.tag_for_under_age_of_consent = AgeGate.band() != AgeGate.ADULT
	UserMessagingPlatform.consent_information.update(request, _on_consent_updated, func(error: FormError) -> void:
		Analytics.track("consent_failed", {"error": error.message if error else ""})
		_init_ads())
```

- [ ] **Step 1: Write `core/ad_pacing.gd`**

```gdscript
extends RefCounted

## When a full-screen ad may show, and how many rewarded videos are left
## today. Pure: the caller hands in the clock, the date, the day's hearts and
## the age band, so a probe can walk weeks in a loop. core/ads.gd owns one and
## saves `state` after every change. The numbers are the research report's
## starting points (reports/Fair ad monetization for puzzles.md), overridable
## by the remote config/ads document through merge().

const AgeGate = preload("res://core/age_gate.gd")
const Wallet = preload("res://core/wallet.gd")

const DEFAULTS := {
	"interstitial_on": true,
	"grace_days": 3,
	"after_hearts": 3,
	"min_games_today": 6,
	"games_between": 2,
	"minutes_between": 4.0,
	"after_rewarded_minutes": 4.0,
	"max_per_day": 4,
	"rewarded_per_day": 10,
}

var cfg: Dictionary = DEFAULTS.duplicate()
var state := {
	"first_day": 0, "day": 0, "games_today": 0, "games_since": 0,
	"shown_today": 0, "last_full": 0.0, "last_rewarded": 0.0, "rewarded_today": 0,
}

## Takes the remote numbers it knows, of the type it expects; anything else
## is ignored, so a bad document can never switch pacing off by accident.
func merge(remote: Dictionary) -> void:
	for k: String in remote:
		if not cfg.has(k):
			continue
		var want := typeof(DEFAULTS[k])
		var v = remote[k]
		if want == TYPE_BOOL and typeof(v) == TYPE_BOOL:
			cfg[k] = v
		elif want in [TYPE_INT, TYPE_FLOAT] and typeof(v) in [TYPE_INT, TYPE_FLOAT]:
			cfg[k] = maxf(0.0, float(v))

func _roll(today: int) -> void:
	if int(state.first_day) == 0:
		state.first_day = today
	if int(state.day) != today:
		state.day = today
		state.games_today = 0
		state.shown_today = 0
		state.rewarded_today = 0

func note_finished(today: int) -> void:
	_roll(today)
	state.games_today = int(state.games_today) + 1
	state.games_since = int(state.games_since) + 1

func interstitial_verdict(now: float, today: int, hearts: int, band: int) -> String:
	_roll(today)
	if not bool(cfg.interstitial_on):
		return "off"
	if band == AgeGate.CHILD:
		return "child"
	if Wallet._days_between(int(state.first_day), today) < int(cfg.grace_days):
		return "grace"
	if hearts < int(cfg.after_hearts):
		return "hearts"
	if int(state.games_today) < int(cfg.min_games_today):
		return "few_games"
	if int(state.games_since) < int(cfg.games_between):
		return "games_between"
	if now - float(state.last_full) < float(cfg.minutes_between) * 60.0:
		return "minutes_between"
	if now - float(state.last_rewarded) < float(cfg.after_rewarded_minutes) * 60.0:
		return "after_rewarded"
	if int(state.shown_today) >= int(cfg.max_per_day):
		return "day_cap"
	return ""

func note_interstitial(now: float, today: int) -> void:
	_roll(today)
	state.last_full = now
	state.games_since = 0
	state.shown_today = int(state.shown_today) + 1

func rewarded_left(today: int) -> int:
	_roll(today)
	return maxi(0, int(cfg.rewarded_per_day) - int(state.rewarded_today))

func note_rewarded(now: float, today: int) -> void:
	_roll(today)
	state.last_rewarded = now
	state.rewarded_today = int(state.rewarded_today) + 1
```

```gdscript
## A small settings document (config/<name>), for numbers worth changing
## without a release: the ad pacing's today. Cache first, network behind.
static func config(name: String) -> Dictionary:
	var cache := "%s/config-%s.json" % [CACHE_DIR, name]
	var cached := {}
	if FileAccess.file_exists(cache):
		var d = JSON.parse_string(FileAccess.get_file_as_string(cache))
		cached = d if typeof(d) == TYPE_DICTIONARY else {}
	if not started() or not await _ensure_token():
		return {"ok": not cached.is_empty(), "data": cached, "error": "offline"}
	var res := await _http("%s/config/%s" % [_docs(), name], HTTPClient.METHOD_GET,
		["Authorization: Bearer %s" % _id_token], "")
	if not res.ok:
		return {"ok": not cached.is_empty(), "data": cached, "error": str(res.error)}
	var doc = JSON.parse_string(str(res.body))
	var fields = doc.get("fields", {}) if typeof(doc) == TYPE_DICTIONARY else {}
	var raw = fields.get("json", {}).get("stringValue", "") if typeof(fields) == TYPE_DICTIONARY else ""
	var parsed = JSON.parse_string(str(raw))
	if typeof(parsed) != TYPE_DICTIONARY:
		return {"ok": not cached.is_empty(), "data": cached, "error": "bad payload"}
	DirAccess.make_dir_recursive_absolute(CACHE_DIR)
	var f := FileAccess.open(cache, FileAccess.WRITE)
	if f != null:
		f.store_string(JSON.stringify(parsed))
	return {"ok": true, "data": parsed, "error": ""}
```
