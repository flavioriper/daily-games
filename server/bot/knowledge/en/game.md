# The game

Daily Puzzles is a game of small puzzles and brighter days. The first screen is a grid of boards, and every board has a new puzzle every day.

Most boards have four levels: Easy, Medium, Hard and Insane. A board that asks which level you want gives each level its own puzzle for the day, and each keeps its own done mark.

The Streak tab keeps the days you came back, and the Stats tab shows how you are doing. A gift waits for every day you come back; miss a day and the week waits for you, miss two and it starts again.

Every board trains one of six skills: Words, Logic, Space, Planning, Focus or Memory. When you finish a puzzle, the game shows how that skill is doing and suggests a board for the one you have trained least.

Every board plays offline. The daily theme and a few extras need the internet.
