# Jogos de palavras

Hidden Word. Cinco letras, seis tentativas. Uma palavra nova por dia. Seu lema: "Encontre a palavra oculta".

Word Trail. Trace cada palavra escondida. Os tamanhos são a única pista. Seu lema: "Cada letra acha seu caminho".

Honeycomb. Sete letras num favo, a abelha rainha na do meio. Forme palavras com a letra dela e despeje o mel no pote. Seu lema: "Cada palavra é mel".

Four Shelves. Potes de geleia na cristaleira da despensa escondem prateleiras de quatro palavras que combinam. Ache todas as prateleiras. Seu lema: "Quatro que combinam".

Cross Stitch. Seis palavras se cruzam num bordado, as letras costuradas nos lugares errados. Troque duas de cada vez até cada letra ficar no lugar. Seu lema: "Cada letra no seu lugar".

Padlock. Um cadeado com discos de letras. Gire-os até a janela formar palavras; acenda cada letra de cada disco e o cadeado abre. Seu lema: "Toda letra acesa, o cadeado abre".

Biscuit Tin. Uma lata de biscoitos quebrados, com letras de glacê em cada pedaço. Ponha pedaços no prato para formar palavras; quatro que formam uma palavra longa fazem um biscoito inteiro. Seu lema: "Todo biscoito inteiro, a lata está pronta".

Stepping Stones. Um riacho com uma palavra em cada margem. Ponha pedras para atravessar, cada uma uma palavra com uma letra diferente da anterior, e chegue à outra margem com o mínimo de pedras. Seu lema: "Uma letra por vez, de margem a margem".

Garden Fence. Um canteiro com uma letra em cada estaca da cerca. Estique o barbante de estaca em estaca formando palavras, cada uma começando onde a anterior terminou, até todas as estacas florirem. Seu lema: "Toda estaca em flor".

Five Clues. Cinco cartas de pista viram uma de cada vez, cada uma uma coisa de uma mesma ideia escondida. Diga a ideia com o mínimo de pistas. Seu lema: "Quanto menos pistas, melhor".

Golden Acorn. Um quiz diário. Quatro respostas, uma certa: escolha, confirme e descubra o porquê. Seu lema: "Tem certeza?".

How Big?. Duas silhuetas, uma no tamanho real. Puxe a outra até ficar do tamanho certo ao lado dela. Seu lema: "Meça no olho".

Pearl Dive. Diga um tipo de coisa contra o relógio. Quanto mais rara a resposta, mais fundo o mergulho. Seu lema: "Quanto mais rara, mais fundo.".
