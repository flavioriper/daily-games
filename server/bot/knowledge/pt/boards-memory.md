# Jogos de memória

Glimpse. Uma figurinha aparece por alguns segundos. Remonte-a conta por conta de memória. Seu lema: "Olhe uma vez, lembre".

Birdsong. Um pica-pau bate um ritmo na árvore velha. Bata o mesmo ritmo no tambor; a cada rodada ele soma uma batida. Seu lema: "Ouça e bata de volta".

Teacups. Xícaras de cabeça para baixo na mesa do chá, uma criaturinha escondida debaixo de cada. Levante duas por vez e encontre todos os gêmeos. Seu lema: "Lembre onde você viu".
